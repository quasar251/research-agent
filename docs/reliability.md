# 可靠性设计 Reliability

> 生产级横切关注点：LLM 与工具调用的容错、幂等、断点恢复。本文是各模块的公共可靠性规范，`orchestration.md` / `context.md` 引用本文。

---

## 1. 错误分类

所有外部调用先归类，决定重试策略：

| 错误类别 | 判定 | 处理 |
|---|---|---|
| 可重试（瞬时） | 超时、429 限流、5xx、网络抖动 | 指数退避重试 |
| 可重试（可恢复） | JSON 解析失败、schema 校验失败 | 重试（换采样参数），重试仍失败则降级 |
| 不可重试 | 401 鉴权失败、参数非法、注入命中 | 立即失败，记审计 |
| 静默缺口 | 缺口未被处理也未标 unresolved | 禁止出现，见 `orchestration.md` |

---

## 2. LLM 调用可靠性

- **超时**：单次 `complete` 默认 60s，可配置。
- **重试**：可重试错误最多重试 3 次，指数退避（1s → 2s → 4s）。
- **结构化输出**：用 anthropic tool use 强制 schema，非法输出视为「可重试（可恢复）」，重试后仍失败则**降级**。
- **降级**：降级链为「当前模型重试 → 换更小/更快模型 → 返回带 `partial=true` 的部分结果并显式标注未完成」。
- **熔断**：同一模型连续 5 次失败进入熔断，冷却 30s 后再放行，期间直接走降级。

---

## 3. 工具调用可靠性

- **超时**：单次工具调用默认 30s，可配置。
- **重试**：仅幂等的工具（抓取、搜索）可重试；写操作（数据库写入）不自动重试，由上层幂等键保证。
- **错误码**：工具返回结构化错误码（超时 / 限流 / 鉴权 / 参数 / 网络），调用方据此分类（见 §1）。

---

## 4. 幂等性

- **run 级幂等**：以 `run_id` 为幂等键。同一个 `run_id` 重复执行，不重复创建台账、不重复计费，直接返回已存在的结果或从检查点恢复。
- **子任务级幂等**：子任务 id 全局唯一，重派时用 `_upsert_by_id` 合并，不产生重复条目。
- **工具写操作幂等**：数据库写入带幂等键，重复调用不产生副作用。

---

## 5. 断点恢复

- **检查点粒度**：每个 super-step（四阶段边界）落一次检查点（见 `state.md` 检查点）。
- **恢复语义**：崩溃后从最近检查点续跑，**不重放已完成阶段**，结果与不中断一致（确定性续跑）。
- **恢复入口**：`run_id` → 查询最新检查点 → 若存在则从该检查点继续，否则从头开始。
- **超时兜底**：任务级硬超时（默认 30 分钟），超时则把当前状态落检查点并标 `unresolved`，不悬挂。
