# 研衡 · 深度调研流程（deep）

> 面向深度研究结论的场景。五阶段完整流程，含并行分叉与三处用户审批（HITL），保障结论严谨可控。

---

## 一、调研定位

深度调研适用于「需要完整、可信、可复核结论」的需求，追求严谨与可控：

- 目标：覆盖从行业概览到结论建议的完整八章报告。
- 特点：多 Agent 并行协作、阶段间设人工审批、交叉审查校验结论。
- 产出：一份「头部指标 + 核心结论 + 正文八章 + 信息来源」的完整报告。

---

## 二、参与角色

| 角色 | 职责 |
|---|---|
| Master | 规划任务、主笔整合、生成最终报告 |
| Scout | 检索外部信息源（机构报告、论文、财报、政策） |
| Analyst | 数据结构化、产业链与竞争分析、市场规模估算 |
| Critic | 交叉审查，回溯结论出处，提出修订意见 |

---

## 三、流程概览

深度调研在规划后进入并行分叉：Scout 与 Analyst 同时作业，汇合后由 Critic 交叉审查，最后 Master 整合输出：

```
        Master（规划 & 主笔）
         /        \
    Scout        Analyst      ← 并行执行
         \        /
        Critic（交叉审查）
            │
        Master（整合生成报告）
```

Critic 的修订意见会以「反馈线」回流到 Master，在生成报告阶段被采纳。

---

## 四、详细执行步骤

### 阶段一 · 任务拆解（Master）

1. **解析主题**：明确调研目标、范围与预期结论。
2. **规划任务边界与依赖**：把大主题拆成相互独立的子任务，标注先后依赖关系。
3. **匹配 Agent**：为任务分配合适的执行角色（Scout ×2、Analyst ×2）。
4. **分发任务**：把 4 项子任务派发给对应 Agent。

> 本阶段约 6.5s，产出任务清单与分工方案。**需要用户审批**，通过后才进入下一阶段。

### 阶段二 · 数据检索（Scout + Analyst）

1. **多渠道检索**：Scout 分别从多个来源收集材料——IDC / Gartner（9 篇）、arXiv（17 篇）、财报（4 家）、政策库（3 份）。
2. **过滤去噪**：从海量材料中筛选，保留 42 条高价值信息源。
3. **结构化**：Analyst 把筛选后的信息整理为结构化数据表，供后续分析使用。

> 本阶段约 9.5s，产出可用的结构化数据集。**需要用户审批**。

### 阶段三 · 深度分析（Analyst）

1. **产业链图谱**：梳理上、中、下游结构，明确各环节关系。
2. **竞争分析**：用波特五力模型分析竞争态势。
3. **市场规模估算**：自下而上估算市场规模，并测算复合增长率（CAGR）。
4. **交叉验证**：汇总分析结果，生成 SWOT 矩阵。

> 本阶段约 6.5s，产出产业链图谱、市场规模与 SWOT。**需要用户审批**。

### 阶段四 · 交叉审查（Critic）

1. **回溯出处**：逐条核对 SWOT 结论背后的数据来源。
2. **口径比对**：与 Gartner 口径比对，确保误差小于 2%。
3. **核验增长率**：复查增长率数字的合理性。
4. **反馈修订意见**：把发现的问题整理成修订意见，回流给 Master。

> 本阶段约 7s，无审批，审查结果直接用于后续修正。

### 阶段五 · 生成报告（Master）

1. **合并产出**：汇总前四阶段全部结果。
2. **八章排版**：按「行业概览 → 市场规模 → 产业链 → 竞争格局 → 趋势研判 → 风险提示 → SWOT → 结论建议」组织报告。
3. **采纳修订意见**：应用 Critic 的修订意见，修正报告内容。
4. **生成引用索引**：整理全部引用来源，形成引用清单。

> 本阶段约 6s，无审批，输出最终报告。

---

## 五、报告结构

深度报告的最终产出由「头部 + 核心结论 + 正文八章 + 信息来源」四部分组成，正文章节如下：

| 章节 | 内容 | 呈现形式 |
|---|---|---|
| 1. 行业概览 | 行业定义、所处阶段、底层确定性来源 | 文字段落 |
| 2. 市场规模 | 历年规模与预测值、复合增长率（CAGR） | 折线图 |
| 3. 产业链图谱 | 上中下游各环节与价值分布 | 要点清单 |
| 4. 竞争格局 | 头部厂商份额与护城河 | 条形图 |
| 5. 趋势研判 | 行业演进方向与结构性变化 | 要点清单 |
| 6. 风险提示 | 关键风险与制约因素 | 要点清单 / 风险矩阵 |
| 7. SWOT 分析 | 优势 / 劣势 / 机会 / 威胁 | 四象限矩阵 |
| 8. 结论与建议 | 收尾结论与可执行建议 | 文字段落 |

头部展示核心指标与摘要，正文前附「核心结论 KEY TAKEAWAYS」要点，结尾附「信息来源 References」引用索引。

---

## 六、审批机制（HITL）

深度调研在阶段一、二、三结束后各设一处人工审批：

- **通过**：继续执行下一阶段。
- **打回重写**：重新执行当前阶段，修正后再提交审批。

阶段四、五无需审批，由系统自动完成审查与成稿。

---

## 七、进度提示

顶部进度条共 5 格，对应五个阶段：

1. 任务拆解
2. 数据检索
3. 深度分析
4. 交叉审查
5. 生成报告

进度条随阶段推进点亮，审批通过后继续推进；打回重写则停留在当前阶段直至再次通过。
