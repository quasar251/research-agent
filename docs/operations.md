# 部署与运维 Operations

> 生产级运维规范：环境配置、密钥管理、监控告警、CI。

---

## 1. 部署形态

ToC 单用户，单进程部署即可，无需集群：

- **进程**：单个 FastAPI（uvicorn）承载 HTTP + SSE + 后台任务。
- **后台任务**：调研任务在进程内异步执行（`asyncio` 任务队列），不引入独立 worker。
- **持久化**：单文件 SQLite（检查点 + 台账），备份即拷贝文件。

---

## 2. 配置与环境

| 配置项 | 来源 | 说明 |
|---|---|---|
| `ANTHROPIC_API_KEY` | 环境变量 | 模型密钥，**不进代码、不进仓库** |
| `MODEL` | 环境变量 | 默认 `claude-sonnet-4-5` |
| `DB_PATH` | 环境变量 | 默认 `checkpoints.sqlite` |
| `LLM_TIMEOUT_S` | 环境变量 | 默认 60 |
| `TASK_TIMEOUT_S` | 环境变量 | 默认 1800 |

环境分 `dev` / `prod`，差异仅在于密钥与日志级别。

---

## 3. 密钥管理

- 密钥只从环境变量读取，启动时校验缺失（缺失则 fail-fast，报明确错误）。
- 禁止在日志、审计事件、错误信息中输出密钥或含密钥的请求头。
- 密钥轮换：改环境变量重启即可，不涉及代码变更。

---

## 4. 监控与告警

监控四类指标（具体定义见 `observability.md` §3）：

| 类别 | 关键指标 | 告警阈值（建议） |
|---|---|---|
| 可用性 | 接口错误率、熔断状态 | 错误率 > 5% 持续 5 分钟 |
| 时延 | LLM 调用 p95、任务总时长 | p95 超预算 2 倍 |
| 质量 | 覆盖度、unresolved 占比 | unresolved 占比 > 20% |
| 成本 | token 消耗、重试次数 | 重试占比 > 15% |

---

## 5. 日志

- 结构化日志（JSON），统一字段：`timestamp`、`level`、`run_id`、`thread_id`、`event`、`payload`。
- 级别：`INFO`（正常流程）/ `WARN`（重试、降级）/ `ERROR`（失败、熔断）。
- 日志脱敏：命中隐私脱敏规则的内容不进日志原文（见 `security.md` 边界二）。

---

## 6. CI 与发布

- **CI**：PR 触发 `pytest`（单测 + 集成）+ 覆盖率门禁（见 `functional-test.md`）。
- **发布**：语义化版本，打 tag 触发构建。
- **回滚**：SQLite 文件 + 代码可整体回滚；检查点 schema 迁移需向后兼容（见 `state.md`）。
