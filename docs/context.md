# 上下文 Context

> 本文对应《扩展设计》`agent-extended.md` 的 §1 上下文模块。
> Context 是「状态 → 视图」的按角色编译，回答"这个 Agent 此刻能看到什么"。

---

## 1. 职责

上下文不是"拼 prompt"，而是**编译一个受控的信息视图**。以 CEMAF 五个质量标准为标尺：

> **相关性、充分性、隔离性、经济性、可溯源**

按 Agent 角色编译不同视图（关键：避免交叉污染判断）：

| 角色 | 上下文内容 | 明确排除 |
| --- | --- | --- |
| Lead | 研究矩阵 + 已完成子任务摘要 + 待补缺口 | 原始抓取全文 |
| 搜集 | 子问题 + 查询历史 + 已覆盖来源列表 | 其他子问题的结论 |
| 核查 | 待核查结论 + 引用来源 + 证据分级规则 | 生成结论的推理过程 |
| 合成 | 所有子任务结论 + 去重规则 | 各子 Agent 的原始检索全文 |

---

## 2. 上下文的组织方式

- **上下文单元**：一条可溯源的原子内容，带类型标记（意图 / 矩阵 / 子任务 / 证据 / 结论 / Skill / 规则）与来源引用。
- **上下文快照**：每次编译落一份快照，记录"该角色看到了哪些来源 / 结论的 id 列表 + 编译参数（角色、预算）"，用于溯源"当时 Agent 看到了什么"。

> 裁剪说明：原设计的"不可变补丁链 + 完整增删回放"是通用 Agent 的重治理机制。调研只需要 **provenance**（结论→来源），用"快照 = 引用列表"即可满足，已移除补丁链。

---

## 3. 与其他模块的耦合

- **读状态**：编译器从状态投影，不持有状态（状态是事实，上下文是视图）。
- **注入 Skill**：Skill 是上下文的一种受控注入形式（见 `skill-design.md`）。
- **产出快照**：每次编译落一份快照，进入审计语义。
- **受安全约束**：检索到的内容一律标记为**不可信数据**，不进入 system instruction 层级。

---

## 4. 关键设计点

- **上下文预算与自动摘要**：搜集 Agent 的对话历史 / 来源列表超预算时触发压缩；**压缩摘要必须保留来源指针**，不能丢可溯源性。
- **每个上下文快照可溯源**：任何一个判断都能追溯到"当时 Agent 看到了什么"。

---

## 5. 生产级关注点

### 5.1 预算压缩阈值

- 预算上限取模型上下文窗口的 **80%**（预留生成空间），可配置。
- 超过阈值触发压缩，降级链见 `reliability.md` §2（压缩是降级手段之一，不丢来源指针）。

### 5.2 token 计量

- 每次编译记录 `token 数` + `预算余量` 到上下文快照。
- 超预算时先压缩、再降级，绝不让模型静默截断上下文。
